# Weather

**Демо:** https://ilya9488.github.io/weather-app/

Додаток погоди на Vue 3 та [OpenWeatherMap API](https://openweathermap.org/): пошук міста з автокомплітом, картка погоди, графік температури, до 5 блоків з різними містами, вибране, прогноз на 5 днів, визначення міста за IP, мови uk/en, денна та нічна тема.

## Стек

- **Vue 3** (Composition API, `<script setup>`), **Vite**
- **Pinia** — стан блоків, вибраного та налаштувань
- **Vue Router** — вкладки «Головна» / «Вибране» (hash-режим, працює на будь-якому статичному хостингу)
- **vue-i18n** — інтерфейс uk/en
- **axios** — запити до API
- **Chart.js** — графіки (напряму, без `vue-chartjs`)
- Стилі — чистий CSS з custom properties, без CSS-фреймворків і UI-бібліотек
- **Vitest** — юніт-тести, **ESLint** + **Prettier**

## Запуск

Потрібен Node.js 20.19+.

```bash
npm install
npm run dev
```

Ключ OpenWeatherMap уже прописаний у `.env`, щоб проєкт запускався одразу після клонування (у клієнтському додатку ключ однаково видно в зібраному JS). Щоб використати свій ключ, замініть `VITE_OWM_API_KEY` у `.env` або створіть `.env.local` за зразком `.env.example`. Отримати ключ: https://home.openweathermap.org/api_keys

| Команда           | Що робить                         |
| ----------------- | --------------------------------- |
| `npm run dev`     | Dev-сервер                        |
| `npm run build`   | Production-збірка в `dist/`       |
| `npm run preview` | Перегляд production-збірки        |
| `npm run test`    | Юніт-тести                        |
| `npm run lint`    | ESLint                            |

## Деплой

Збірка — статичні файли з `dist/`, тому підходить будь-який хостинг.

**GitHub Pages** (налаштовано в `.github/workflows/deploy.yml`): після push у `main` проєкт перевіряється (lint, тести), збирається й публікується в гілку `gh-pages`.

- Pages: Settings → Pages → Source: **Deploy from a branch**, гілка `gh-pages`, папка `/ (root)`.
- Необов'язково: щоб зібрати з іншим ключем, додайте secret `VITE_OWM_API_KEY` (Settings → Secrets and variables → Actions) — він має пріоритет над `.env`.

**Vercel / Netlify**: build command `npm run build`, output `dist`, змінна оточення `VITE_OWM_API_KEY`.

## Пошук міст

OpenWeatherMap Geocoding API знаходить місто лише за повною назвою («Київ» — так, «Киї» — ні), тому для автокомпліту запити йдуть паралельно у два джерела:

- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) (безкоштовний, без ключа) — підказки за частиною назви, відсортовані за населенням, назви українською та англійською;
- для запиту кирилицею — ще й його транслітерація за офіційними правилами (постанова КМУ № 55), бо невеликі села Open-Meteo знає лише латиницею («Крюківщ» → «Kriukivshch» → Крюківщина);
- OpenWeatherMap Geocoding — точні збіги за повною назвою та українські назви для таких сіл.

Результати об'єднуються без дублікатів і кешуються на час сесії; якщо одне джерело недоступне, працює інше. Погода й прогноз — лише з OpenWeatherMap.

Однакових назв буває багато (Тарасівок в Україні понад 50), тому:

- у списку до 15 варіантів із районом та областю;
- великі міста (від 100 тис.) йдуть першими, решта — від найближчого до користувача (місцезнаходження за IP);
- область можна уточнити через кому: «Тарасівка, Київська».

## Встановлення як застосунок (PWA)

Додаток можна встановити на телефон або комп'ютер — він відкривається окремим вікном без панелі браузера, з власною іконкою.

- **Android / Chrome / Edge** — кнопка «Встановити» в шапці або пункт «Встановити застосунок» у меню браузера.
- **iPhone / iPad** — у Safari «Поділитися» → «На початковий екран» (кнопка в шапці показує цю підказку).

Service worker ([vite-plugin-pwa](https://vite-pwa-org.netlify.app/)) кешує оболонку застосунку та останні завантажені дані погоди, тож без мережі видно останній прогноз. Нова версія підхоплюється автоматично.

## Додатково (п. 14)

- **Встановлюється як застосунок** на Android, iOS і десктоп, без мережі показує останні дані.
- **Усе зберігається між перезавантаженнями**: блоки з містами та режимом день/5 днів, вибране з режимами, мова, тема.
- **Доступність**: ARIA combobox в автокомпліті, навігація стрілками, Enter, Esc; модальні вікна на `<dialog>` з фокусом і закриттям по Esc; таблиця значень графіка для скрінрідерів; `prefers-reduced-motion`.
- **Кеш відповідей API** на 10 хвилин — те саме місто на головній і у вибраному не запитується двічі; застарілі запити автокомпліту скасовуються.
- **Зрозумілі помилки** з кнопкою «Спробувати ще раз»: немає або недійсний ключ, ліміт запитів, немає мережі.
- **Власні SVG-іконки погоди**, що підлаштовуються під тему.
- Лічильник міст у вкладці «Вибране».
